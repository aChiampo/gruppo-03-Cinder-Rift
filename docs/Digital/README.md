# Area Digital

Documentazione sintetica dei Digital Strategist: contenuti, strategia, economia e regole condivise. I contenuti definitivi saranno forniti dal gruppo.

Applicare progressivamente le sezioni pertinenti del [modello](../modello-funzionalita.md):
fonti, decisioni, regole, ipotesi, metriche, criteri e verifiche dei materiali.
Collegare le conseguenze per FrontEnd e BackEnd senza duplicare i contratti tecnici.
Stato corrente nell'[indice generale](../README.md#stato-delle-funzionalità).
